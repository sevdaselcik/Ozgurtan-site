# Özgür Tan – Custom Build Project Site

Bu proje, özel araç tasarımı ve mühendisliği yapan Özgür Tan için hazırlanmıştır.

## Özellikler

- HTML + CSS ile sade, estetik ve Web 3.0 ruhunu taşıyan tasarım
- Danışmanlık, 3D tasarım, parça üretimi ve özel araç yapımı hizmetleri
- Fleek, Netlify veya IPFS ile yayınlanmaya hazır

## Yayınlama

1. Bu klasörü GitHub'a yükle
2. Fleek üzerinden bağlanıp IPFS'e yükle
3. (İsteğe bağlı) ENS alan adı ile entegre et
